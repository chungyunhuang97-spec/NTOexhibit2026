# 德國行程 2027

佑辰與弟弟 2027/1/11–1/22 的行程 Web App：法蘭克福（Heimtextil 1/12–15）→ 慕尼黑 → 布拉格。
手機以查看與現場導航為主，電腦用來在台灣排行程。三人可共同編輯。

## 功能

| 頁面 | 內容 |
|---|---|
| 總覽 | 倒數、城市夜數、待處理訂票（依截止日）、12 天時間軸（交通、景點、住宿一行看完） |
| 行程 | 電腦：左列表右地圖、拖曳排序。手機：全螢幕地圖 + 三段式底部抽屜 + 右下角新增按鈕 |
| 訂票 | 航班、交通、住宿、門票、出發準備；點狀態即可切換未訂 → 已訂 → 已付款 |
| 購物 | 各城市購物清單、退稅單據追蹤、逛街須知 |

- **地點搜尋**：Photon 即時聯想 + Nominatim 進階搜尋（Enter），範圍限德國、捷克，內建繁中別名（新天鵝堡 → Schloss Neuschwanstein）
- **選擇結果**：地圖飛過去，卡片自動帶入中文名、當地原名、地址、座標、類型
- **導航**：每張卡片有「在 Google Maps 開啟」與「導航」（大眾運輸），設定中可改用 Apple 地圖
- **冬季規則**：戶外景點超出 11:00–15:00 會提示；德國週日排購物會提示；顯示日出日落、天氣（出發前 16 天內）
- **1/16 備案**：方案 A 新天鵝堡 / 方案 B Ingolstadt Village，可切換，地圖與交通跟著變
- **離線**：PWA，可加到主畫面；行程資料與看過的地圖會快取
- **雙時區**：台灣與德國・捷克目前時間

## 開發

```bash
npm install
npm run dev
```

## 啟用三人共享編輯（Supabase）

沒有設定時是「本機模式」，資料只存在當下的瀏覽器。

1. 在 Supabase 建立專案（區域建議 `eu-central-1` 法蘭克福）
2. 到 SQL Editor 貼上並執行 `supabase/schema.sql`
3. 在部署平台（Vercel）設定環境變數，值在 Project Settings → API：
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`（publishable key）
4. 重新部署，打開網站 → 右上角設定 → 設定編輯 PIN →「建立共享旅程」
5. 把網址（含 `?t=...`）和 PIN 傳給佑辰和弟弟；第一次編輯時輸入 PIN 即可

安全設計：表格不開放直接存取，所有讀寫都經過資料庫函式；讀取需要旅程連結，寫入需要 PIN（bcrypt 雜湊）。即時同步使用 Supabase Realtime broadcast。
